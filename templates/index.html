PROGRAMMATIC REST API DOCUMENTATION

                
Integrate OpsFlow Cloud directly into your external microservices, webhooks, or third-party CRM platforms. All requests support Bearer API Key authentication or Session cookies.

                

                    Base URL: /api/v1
                    Auth Header: X-API-Key: sk_live_...
                

            


            

                
                

                    

                        

                            POST
                            /api/v1/events/ingest
                        

                        Permission: Ingest / Write
                    

                    
Ingests an incoming event (e.g. lead.created, system.metrics, customer.inquiry) and triggers matching workflows.

                    


curl -X POST https://your-domain.onrender.com/api/v1/events/ingest \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sk_live_your_key_here" \
  -d '{
    "event": "lead.created",
    "name": "Jane Smith",
    "email": "jane@enterprise-client.com",
    "message": "We need enterprise automation for 500 team members with a $40,000 annual budget.",
    "phone": "+1 (555) 987-6543",
    "dry_run": false
  }'

                    

                    
Response: 200 OK with executed rules, condition results, AI analysis, and CRM lead record ID.

                


                
                

                    

                        

                            GET
                            /api/v1/workflows
                        

                        Permission: Read
                    

                    
Lists all configured workflows, visual steps, and triggers for the active workspace.

                    


curl -X GET https://your-domain.onrender.com/api/v1/workflows \
  -H "X-API-Key: sk_live_your_key_here"

                    

                


                
                

                    

                        

                            POST
                            /api/v1/workflows/{id}/execute
                        

                        Permission: Execute
                    

                    
Triggers explicit immediate execution of a specific workflow rule with custom payload. Supports "dry_run": true for zero side effects.

                


                
                

                    

                        

                            GET
                            /api/v1/leads?status=qualified
                        

                        Permission: Read
                    

                    
Returns paginated CRM leads filtered by status or search terms, complete with predictive lead score and AI draft response.

                


                
                

                    

                        

                            GET
                            /health
                        

                        Public / Load Balancer
                    

                    
Cloud health probe returning database connectivity, engine online status, and service uptime. Used by Render and Kubernetes liveness probes.
