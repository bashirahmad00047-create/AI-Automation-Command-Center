REST API Reference & Developer Hub

                
Integrate BashFlow Cloud directly into your external microservices, webhooks, or third-party CRM platforms. All requests support Bearer API Key authentication or Session cookies.

                

                    Base URL: /api/v1
                    Auth Header: X-API-Key: sk_live_...
                

            


            

                
                

                    

                        

                            POST
                            /api/v1/events/ingest
                        

                        Permission: Ingest / Write
                    

                    
Ingests an incoming event (e.g. lead.created, system.metrics, customer.inquiry) and triggers matching workflows.

                    


curl -X POST https://your-domain.onrender.com/api/v1/events/ingest \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sk_live_your_key_here" \
  -d '{
    "event": "lead.created",
    "name": "Jane Smith",
    "email": "jane@enterprise-client.com",
    "message": "We need enterprise automation for 500 team members with a $40,000 annual budget.",
    "phone": "+1 (555) 987-6543",
    "dry_run": false
  }'

                    

                    
Response: 200 OK with executed rules, condition results, AI analysis, and CRM lead record ID.
